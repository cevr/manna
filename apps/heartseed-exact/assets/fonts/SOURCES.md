# The reading fonts' sources

The seven families Heartseed bundles for its reading settings (q121), each under the SIL Open Font License 1.1. Every file is the upstream file, unmodified and unrenamed (no subset, no conversion), so no Reserved Font Name is touched. Each folder holds its family's licence as `OFL.txt`, which About's licences ship (`tools/licences.ts`). `src/type/fonts.test.ts` holds every file to the SHA-256 written here.

The fourteen font files total 3,338,724 bytes (3.2 MiB), under the plan's 5 MB. Each version is the file's own (`name` id 5). Where a release ships static files they are taken from it; Merriweather, Atkinson Hyperlegible and OpenDyslexic publish no release with static files, so theirs come from the family's own repository at the commit named. The KJV the app ships uses 62 characters, all ASCII, and every face draws each of them (`src/type/fonts.test.ts`).
